# Glossary

- **Browsing data:** Local storage mapping a calendar date to seconds per site.
- **Foreground time:** Time a non-incognito HTTP(S) tab is active in the focused browser window and the browser is not idle or locked.
- **Site:** A hostname with a single leading `www.` removed; other subdomains are separate sites.
- **Tracker state:** Session-only active hostname, interval start time, and paused/tracking status.
